# Vamary

Plastic surgery & aesthetic clinic — Next.js 16 application

## Run

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm start
```

## Structure

- `app/` — routes and layout (English, LTR)
- `components/` — UI, layout, sections, shared
- `data/` — static English content
- `public/images/` — migrated assets
